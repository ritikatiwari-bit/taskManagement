# taskManagement

TaskFlow - Task Management Application

## Project Title

TaskFlow - Task Management Application


## Project Objective

The objective of this project is to develop a responsive and interactive task management web application using HTML5, CSS3 and JavaScript.

The project demonstrates the concepts learned during the six-week web development internship, including semantic HTML, CSS styling, Flexbox, Grid, responsive design, JavaScript functions, arrays, objects, DOM manipulation and event handling.

Git and GitHub are used for version control and GitHub Pages is used for deployment.

## Project Overview

TaskFlow is a simple task management application that allows users to organize and manage their daily tasks.

Users can:

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks
- Set task priority
- Set due dates
- View task statistics

Task information is stored using browser Local Storage, allowing tasks to remain available after refreshing the webpage.

## Main Features

    ### 1. Add Task

    Users can add a new task by entering:
    - Task title
    - Description
    - Due date
    - Priority

    ### 2. Edit Task
    Existing tasks can be edited using the Edit button.

    ### 3. Delete Task
    Users can delete tasks after confirming the deletion.

    ### 4. Complete Task
    Tasks can be marked as completed or changed back to pending.

    ### 5. Search
    Users can search tasks by title or description.

    ### 6. Filter
    Tasks can be filtered by:
    - All
    - Pending
    - Completed
    - High Priority
    - Medium Priority
    - Low Priority

    ### 7. Task Statistics
    The dashboard displays:
    - Total tasks
    - Pending tasks
    - Completed tasks
    - High priority tasks

    ### 8. Form Validation
    The application validates the task title, description and due date.

    ### 9. Local Storage
    Task information is stored in the browser using Local Storage.

    ### 10. Responsive Design
    The website works on:
    - Desktop
    - Tablet
    - Mobile
